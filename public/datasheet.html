Product Description

Overview

The Absolute Unit 17 is a compact, high-performance closed-loop stepper motor controller specifically designed for NEMA 17 stepper motors. It integrates an ESP32-C6 microcontroller, TMC2209 stepper driver, AS5600 magnetic rotary encoder, and CAN bus transceiver into a single 42mm × 42mm PCB — making it ideal for robotics, CNC, 3D printing, and precision motion control applications.

Key Features

  • True closed-loop control with 12-bit absolute position feedback
  • Ultra-silent operation via TMC2209 StealthChop technology
  • CAN bus networking for multi-axis daisy-chain configurations
  • Wi-Fi 6 and Bluetooth 5.0 wireless connectivity
  • USB Type-C for programming and debugging
  • XT30PW power connectors for robust daisy-chain power distribution
  • Compact NEMA 17 mounting-compatible form factor
  • On-board status LED for visual diagnostics

Target Applications

  • Robotic arms & multi-axis systems
  • 3D printers with closed-loop feedback
  • CNC machines & laser engravers
  • Camera gimbals & pan-tilt systems
  • Automated laboratory equipment
  • Smart conveyor systems
  • IoT-connected motion platforms
Designed for Integration: The board mounts directly behind a NEMA 17 motor using the standard 31mm mounting pattern. The AS5600 encoder on the back side reads a diametrically magnetized magnet attached to the motor shaft, providing real-time absolute position feedback.

Communication Interfaces

C
CAN Bus Interface

The on-board SN65HVD230QDRG4Q1 CAN transceiver provides a robust, noise-immune differential bus for multi-node communication. Supports CAN 2.0B at up to 1 Mbps. Ideal for daisy-chaining multiple boards in multi-axis configurations. XT30PW connectors provide power and CAN signal pass-through.

I
I2C Bus (AS5600)

The AS5600 12-bit magnetic rotary encoder communicates over I2C at address 0x36. Provides absolute angle measurement with 0.0879° resolution (4096 positions/revolution). Reads a diametrically magnetized magnet on the motor shaft for closed-loop feedback.

U
UART (TMC2209)

Single-wire UART interface for configuring motor current, microstepping, StallGuard sensitivity, and CoolStep parameters at runtime. Default 115200 baud. Enables advanced diagnostics including load measurement, over-temperature detection, and open-load reporting.

W
Wireless (ESP32-C6)

Integrated Wi-Fi 6 (802.11ax) and Bluetooth 5.0 LE via the ESP32-C6 on-chip radio with PCB antenna. Enables OTA firmware updates, wireless parameter tuning, telemetry streaming, and integration with IoT platforms.

Application Notes

1
Closed-Loop Operation

Mount the board on the rear of a NEMA 17 motor with a ∅6mm diametrically magnetized magnet glued to the shaft. The AS5600 detects position and feeds it back to the ESP32-C6, which adjusts step timing to eliminate missed steps.

2
Daisy-Chain Wiring

Connect multiple boards via XT30PW connectors in a daisy-chain topology. Power and CAN bus signals pass through. Terminate the last node with a 120Ω resistor across CAN_H and CAN_L.

3
Firmware Update

Connect via USB Type-C and use ESP-IDF, Arduino IDE, or PlatformIO to flash firmware. The ESP32-C6 also supports OTA updates via Wi-Fi for remote deployment across all nodes.
